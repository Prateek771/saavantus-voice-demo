## Verification and limits

Both real routes were inspected in the in-app browser. At 1440 × 1000 the transcript is beside the particle orb; at 390 × 844 it is underneath, with no horizontal dialog overflow. Escape and the close button return focus to the launcher and restore page scrolling. The existing motion control pauses the renderer. The renderer also gates frames on visibility, intersection and reduced motion.

78 automated checks and TypeScript pass. A review found that a microphone permission granted after closing could leave a stream running if the SDK's startup threw. The application now stops stale audio in a finally block; a regression exercises the installed BrowserAudioInterface and verifies the late stream is stopped. No other review findings remain.

The current provider status is pending. A real microphone conversation, populated live transcript, real audio-driven state transitions and physical-phone performance remain unverified. The existing SDK transcript callback and memory-only transcript retention are preserved. The orb responds to SDK session states, not measured microphone loudness. The generated second concept is a static fallback only; normal rendering uses live projected 3D particles.

No public deployment or provider changes. Work continues in the current local checkout so the existing localhost preview and preceding changes are preserved.
